Local AI Agent Website Source Package

Contents:
- website: local Qwen chat/agent web interface and Python backend
- openclaw-tools: bounded browser/news/workstation integration source
- start/stop launchers and full operating instructions

Required locally:
- Windows
- Ollama with qwen3.5:4b
- Node.js and OpenClaw
- Python environment created from website/standalone-requirements.txt

This source ZIP intentionally excludes model weights, installed dependency folders, browser profiles, cookies, logs, and task history. It contains the website program and custom agent source without private runtime data.
